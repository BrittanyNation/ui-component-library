# UI Component Library Starter — Accessible Components

A small library of hand-built, accessibility-first UI components in vanilla HTML, CSS, and JavaScript: buttons, a modal dialog, tabs, and an accordion — each documented with usage notes.

## Skills demonstrated
- Keyboard support (Tab order, Escape to close, arrow-key tab navigation)
- ARIA roles, states, and properties used correctly (aria-expanded, aria-selected, role=dialog)
- Visible focus styles and sufficient color contrast
- Component documentation: what it does, markup, behavior, accessibility notes

## Files
- `index.html` — live showcase of every component
- `components.css`, `components.js`
- `COMPONENTS.md` — per-component documentation
